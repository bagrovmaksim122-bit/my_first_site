О проекте

Учебный сайт-визитка по дисциплине «Веб-технологии»

Что это за сайт

Этот сайт — моя первая работа по веб-разработке. Задача проекта — разобраться, как устроена HTML-страница, как оформить её с помощью CSS, ускорить вёрстку библиотекой Bootstrap и опубликовать результат в интернете через GitHub Pages.

Сайт состоит из трёх страниц: главной, страницы о проекте и страницы с контактами. Между ними работает общее меню, а вёрстка подстраивается под экран телефона, планшета и компьютера.

Этапы работы

  1. Сверстал структуру страниц семантическими тегами: header, nav, main, section, footer.
  2. Вынес оформление в отдельный файл style.css.
  3. Подключил Bootstrap: сетку, карточки, кнопки, меню и форму.
  4. Проверил адаптивность в DevTools в режиме телефона.
  5. Загрузил файлы на GitHub и включил GitHub Pages.

Технологии

  • HTML5 разметка
  • CSS3 оформление
  • Bootstrap 5 сетка и компоненты
  • GitHub Pages публикация
Сайт опубликован на GitHub Pages и открывается по прямой ссылке.
